# 系統架構設計（草稿）

> 狀態：討論中。車體和吸塵器的尺寸還沒確定。

## 1. 任務分析（期末自走）

```
        (0,300) ┌─────────────────────────────────┐ (300,300)
                │ [TL +0.4/張]       [TR -0.5/張] │ ← 扣分區，固定在右上，經過時要暫停吸塵
                │                                 │
入口/出口 (0,150)│       [中間 綠色 必吸，否則 -10] │
  （車子朝東出發）│                                 │
                │ [BL +0.4/張]       [BR +0.4/張] │
          (0,0) └─────────────────────────────────┘
單位：cm。紙片區 15×15cm，距離牆 15cm，中心點距牆約 22.5cm
辨識標的（紅色圓，直徑 20cm）隨機放在某個角落，車子要開進辨識區並做出反應
```

- **速度分數（65）比吸力分數（32）重要**：2:30 內完成可拿滿分，所以路線要短、行為要可重複
- 正分紙片共 80 張，**至少要吸 30 張**，否則時間分數 ×0.8
- 牆高約 30–40cm，HC-SR04 打得到

## 2. 定位策略：沒有編碼器，用牆壁當參考

| 量測 | 感測器 | 方法 |
|---|---|---|
| 航向角 θ | MPU6050 陀螺儀 z 軸 | 開機時靜止 2 秒估計偏移，之後積分 |
| 前進距離 | 前方 HC-SR04 | 只走「平行牆壁」的直線，用「到前牆的距離」判斷位置 |
| 橫向距離、修正航向 | 右側 HC-SR04 | 沿牆走時維持固定距離；距離的變化率可以反推航向誤差，用來修正陀螺儀漂移 |

為什麼不用 VIO：場地特徵太少、C310 是捲簾快門且幀率低、MPU6050 雜訊大，在 Pi 4 上算力也不夠，風險太高。

| 5 | 左轉朝西 → 前進 | 前方 = 22 |
| 6 | 右轉朝北 → 前進，吸 TL | 前方 = 22 |
| 7 | 掉頭朝南 → 前進 | 前方 = 150 |
| 8 | 左轉朝東 → 前進，吸中間 | 前方 = 150 |

總長約 12m。沿途經過每個角落時，用攝影機尋找紅色圓形；找到後開進辨識區、觸發蜂鳴器，若是右上角就暫停吸塵。
（實際數值要扣掉感測器到車體中心的距離，等車體確定後再調整。）

## 4. 軟硬體架構

```
┌──────────────── Arduino Uno（韌體）────────────────┐
│ MPU6050 @200Hz → 陀螺儀積分算 yaw                  │
│ HC-SR04 ×2 輪流觸發（避免互相干擾）＋中位數濾波     │
│ L298N 馬達 PWM＋航向角速度 PID                      │
│ 安全機制：300ms 沒收到指令就停車                    │
└──────────────── UART 115200（USB）─────────────────┘
                          ↕
┌──────────── Raspberry Pi 4：ROS2 Humble ───────────┐
│ arduino_bridge  /cmd_vel → 序列埠；序列埠 → 感測器 topic │
│ localizer       yaw＋超音波 → /pose                 │
│ mission         任務狀態機（DriveUntil / Turn …）   │
│ vision          紅色圓形偵測 → /target_found        │
│ web_teleop      網頁遙控（期中）、緊急停車           │
│ stream          MediaMTX WebRTC 串流                │
└────────────────────────────────────────────────────┘
```

### ROS2 Topic（暫定）

| Topic | 型別 | 發布者 → 訂閱者 |
|---|---|---|
| `/cmd_vel` | `geometry_msgs/Twist` | mission、web_teleop → arduino_bridge |
| `/imu/yaw` | `std_msgs/Float32` | arduino_bridge → localizer |
| `/range/front`、`/range/right` | `sensor_msgs/Range` | arduino_bridge → localizer、mission |
| `/pose` | `geometry_msgs/Pose2D` | localizer → mission |
| `/target_found` | `std_msgs/Bool` | vision → mission |
| `/vacuum` | `std_msgs/Bool` | mission → arduino_bridge |
