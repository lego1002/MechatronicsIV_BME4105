# firmware：Arduino Uno 韌體

> 🚧 尚未開始

## 負責功能

- 讀取 MPU6050（I²C，A4/A5），陀螺儀 z 軸積分出航向角
- 兩顆 HC-SR04 輪流觸發，避免互相干擾
- 透過 L298N 控制兩顆馬達（2 個 PWM 腳位＋4 個方向腳位）
- 控制蜂鳴器、吸塵器開關
- 安全機制：300ms 沒收到 Pi 的指令就自動停車

## 序列埠協定（草稿，115200 baud）

Pi → Uno：
```
V <線速度 -255~255> <角速度 -255~255>\n   移動
S\n                                       停車
B <0|1>\n                                 蜂鳴器
F <0|1>\n                                 吸塵器
Z\n                                       航向角歸零（車子要靜止）
```

Uno → Pi（約 50Hz）：
```
D <yaw 度> <前方距離 cm> <右側距離 cm>\n
L <訊息>\n                                debug 訊息
```

## 接腳（暫定）

| 元件 | Uno 腳位 |
|---|---|
| MPU6050 SDA / SCL | A4 / A5 |
| HC-SR04 前方 Trig / Echo | 2 / 3 |
| HC-SR04 右側 Trig / Echo | 4 / 7 |
| L298N ENA / ENB（PWM） | 5 / 6 |
| L298N IN1–IN4 | 8 / 9 / 10 / 11 |
| 蜂鳴器 | 12 |
| 吸塵器（繼電器） | 13 |
